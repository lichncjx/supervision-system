## 2. 默认页眉页脚问题原因

上一版 PDF 使用 Chrome 命令行打印参数导出，但浏览器默认打印页眉页脚未被稳定关闭，导致 PDF 页面中出现：

- 顶部默认打印时间；
- 顶部默认文档标题；
- 底部本机 `file:///...` 文件路径；
- 底部浏览器默认页码。

这些内容属于浏览器打印层生成的信息，不是 HTML 正文内容，不能通过普通 CSS 隐藏。

## 3. HTML 打印 CSS 修正

已保留并确认以下打印规则，用于禁用 HTML 内部固定页眉页脚：

```css
.manual-body::before,
.manual-body::after {
  content: none !important;
  display: none !important;
}
```

同时仅做必要分页收口：

- `h2`、`h3` 避免标题内部断页；
- `h3` 避免与紧随其后的段落、列表或表格分离；
- `figure`、`figcaption`、`table`、`.table-wrap`、`.note` 避免内部断页；
- 轻微收紧打印状态下段落、列表、提示块、图片和图注的上下边距。

未改变 A4 页面尺寸、正文可读字号、图片比例、章节顺序或章节起始页设计。

## 4. 重新导出方式

- 使用本机 Google Chrome DevTools Protocol 的 `Page.printToPDF` 重新导出。
- 明确设置 `displayHeaderFooter: false`，从导出工具层关闭浏览器默认页眉页脚。
- 设置 `printBackground: true`，保留背景颜色、表格底色、提示块和截图标注。
- 设置 `preferCSSPageSize: true`，使用 HTML `@page` 中的 A4 页面设置。
- 导出前通过浏览器会话加载并解码全部 22 张截图，避免懒加载图片缺失。
- 未使用外部服务、在线字体、CDN、项目依赖、JavaScript 生成正文或浏览器扩展。
